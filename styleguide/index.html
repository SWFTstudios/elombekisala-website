Style Guide

Internal reference for typography, color, spacing, and components. Hidden from search (noindex + robots.txt). Use these tokens and classes on every new page so type and color stay uniform.

Load order for new pages: normalize.css → components.css → elombekisala.css → tokens.css → base.css → util.css → components.css (system).

Colors

Primary text is light on black. Accent green is for links, CTAs, and highlights. Never set ad-hoc hex colors in page HTML when a token exists.

Typography
